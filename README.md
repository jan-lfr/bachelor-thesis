# Bachelorarbeit – Selective Refinement für zeitabhängige Versagenswahrscheinlichkeiten

Code zur Bachelorarbeit an der TUM, Betreuung: Prof. Ullmann.

Untersucht wird *Selective Refinement* (SR) zur Schätzung zeitabhängiger
Versagenswahrscheinlichkeiten. Als Beispiel dient der korrodierte Biegebalken
(corroded beam) aus dem PHI2-Paper, §4.1.

## Inhalt

- `corroded_beam.py` – Beispiel corroded beam: plain Monte Carlo und skalares SR
- `ergebnisse/` – Ausgabeordner (Plots werden nicht versioniert)

## Voraussetzungen

Python 3 mit `numpy`, `pandas` und `matplotlib`.
